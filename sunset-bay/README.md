# Sunset Bay

An open-world 3D city game that runs in the browser. It's one self-contained `index.html` built on three.js r128, loaded from a CDN.

Walk, drive, ride, sail and fly around a coastal city. Take jobs, dodge the cops, buy businesses and go into buildings.

## Play

- **Live:** once this repo is deployed on Vercel, the game is at `/sunset-bay/`.
- **Local:** open `index.html` in a browser, or serve the folder with any static server.

## Controls (keyboard)

| Key | Action |
| --- | --- |
| W A S D | Move / drive |
| Mouse drag | Look around |
| Shift | Sprint / nitro |
| Space | Jump · handbrake · climb |
| X | Descend (flying) |
| F | Get in / out of vehicles |
| E | Doors, shops, items |
| V | Fly (roadster) |
| Q | Shove · barrel roll |
| H · C · N | Horn · camera · radio |
| P · M | Phone · map |
| Esc | Menu |

On phones there's a joystick on the left, and the buttons on the right change depending on what you're doing.

## Graphics

Open Phone → Settings → Graphics to pick **Low**, **Medium** or **High**. High adds bloom glow and a reflective ocean. Medium and High add sun shadows and reflections on cars and glass.
